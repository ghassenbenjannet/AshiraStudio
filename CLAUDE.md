# Achirah HQ — pour toute session de travail sur ce dépôt

## Ordre de lecture obligatoire au démarrage

1. **`DECISIONS.md`** — l'historique des choix déjà pris, y compris sur les points d'ambiguïté
   résiduelle du CDC. Ne pas re-décider ce qui y est déjà tranché.
2. **`/docs`** — les documents de référence versionnés (CDC Master, CR-*). Toute règle `RG-*` se
   lit ici, jamais par déduction depuis le code existant ou une implémentation antérieure.
   Introuvable → s'arrêter et demander, ne jamais interpréter.
3. Le code lui-même.

## Principe directeur

Le propriétaire et son équipe ne sont pas techniques. Aucune opération courante ne doit exiger
d'éditer un fichier, d'ouvrir un terminal ou de redémarrer le serveur — tout réglage se fait dans
l'interface (voir Paramètres → Configuration).
